## Run locally

This is a static HTML, CSS, and JavaScript portfolio. Clone the repository and open `index.html` in a browser, or serve the folder with any static web server.

```bash
git clone https://github.com/krk-90/kaushik-portfolio.git
cd kaushik-portfolio
```

## Deployment

GitHub Pages is configured to publish the site from the repository's `main` branch and root directory. A push to `main` should trigger the Pages build; allow a short time for the deployed site to refresh.
